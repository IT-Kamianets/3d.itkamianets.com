One scene format, any engine

Scenes live as JSON. Unity reads and writes them, so the data outlives the engine.

  1. 3d-scene-schema defines the scene
  2. 3d-unity-scene loads and saves it in Unity
  3. 3d-unity-spatial turns a scanned room into a scene

Three layers, one direction

Each layer builds on the one below it.

  1. Core packages

    Scenes, assets, interaction, XR, and spatial data.

    3d-*

  3. Constructors

    A starting architecture for one type of game.

    3d-constructor-*

  5. Your game

    Rules, content, and assets stay outside the framework.

    game-<name>-*
