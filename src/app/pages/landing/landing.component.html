Framework ecosystem

Build 3D apps and games from reusable packages

IT Kamianets 3D Engine is a framework ecosystem of core packages, game constructors, and generated game projects, so you do not rebuild the same systems for every new game.

Browse packages Explore constructors

How the architecture works

The ecosystem is divided into three layers. Each layer builds on the one below it.

  1. 1

    Core packages

    Reusable 3d-* packages with shared engine functionality: scene handling, assets, interaction, XR, spatial data, and engine-independent scene structures.

  2. 2

    Constructors

    Higher-level packages built on the core framework. Each constructor is a starting architecture for one type of 3D game or experience.

  3. 3

    Game-specific packages

    Packages generated or created from a constructor for one game. They hold the rules, content, assets, and configuration unique to that project.

3d-* core packages → 3d-constructor-* packages → game-specific packages → final game

From constructor to game

  1. Pick a constructor

    Choose the camera and gameplay style closest to your game.

  2. Generate the project

    The constructor produces game-specific packages composed from core packages.

  3. Add your content

    Put rules, world, units, UI, and assets into your own packages.

  4. Ship the game

    Game logic stays outside the framework, so it is easy to modify and extend.

How to start

  1. Browse the package catalog and open the packages you need.
  2. Follow the installation section on each package page.
  3. Or start from a constructor that already composes the packages for your game type.
