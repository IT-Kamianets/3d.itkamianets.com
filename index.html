Один формат сцени, будь-який рушій

Сцени зберігаються як JSON. Unity читає й записує їх, тож дані переживають рушій.

  1. 3d-scene-schemaописує сцену
  2. 3d-unity-sceneзавантажує й зберігає її в Unity
  3. 3d-unity-spatialперетворює скановану кімнату на сцену
{
  "id": "anchor_door_entry",
  "type": "DOOR_FRAME",
  "parentId": "anchor_wall_north",
  "transform": {
    "position": { "x": 1.5, "y": 0, "z": -3.0 }
  },
  "boundary": [ … ]
}

Три шари, один напрямок

Кожен шар спирається на попередній.

  1. Базові пакети

    Сцени, ресурси, взаємодія, XR і просторові дані.

    3d-*

  3. Конструктори

    Стартова архітектура для одного типу гри.

    3d-constructor-*

  5. Ваша гра

    Правила, контент і ресурси залишаються поза фреймворком.

    game-<name>-*

Пакети

Усі пакети
  • 3d-scene-schemaНезалежна від рушія специфікація сцен: спільна структура сцен, об'єктів, трансформацій, матеріалів, ресурсів і метаданих.Схема v1
  • 3d-unity-coreБазовий пакет виконання IT-Kamianets 3D Engine: спільні системи Unity, конфігурація, утиліти та базова архітектура.Каркас
  • 3d-unity-sceneПакет виконання сцен: завантажує, зберігає, синхронізує й перебудовує 3D-сцени в Unity зі спільної схеми сцен.Рання розробка
  • 3d-unity-assetsПакет керування ресурсами: 3D-моделі, матеріали, текстури, метадані та завантаження ресурсів під час виконання.Заплановано
  • 3d-unity-interactionПакет редагування об'єктів: вибір, переміщення, обертання, масштабування, прив'язка, дублювання та видалення.Заплановано
  • 3d-unity-xrПакет XR: взаємодія в Meta Quest / VR, контролери, відстеження рук, пересування та інструменти XR.Рання розробка
  • 3d-unity-spatialПакет просторових обчислень: сканування кімнат, просторові якорі, межі, поверхні та картографування реального середовища.Рання розробка
